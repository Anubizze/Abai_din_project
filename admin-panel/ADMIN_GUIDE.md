# Руководство по использованию админ-панели

## Настройка Storage для загрузки фотографий

Перед использованием функции загрузки фотографий необходимо создать Storage bucket в Supabase:

1. Откройте Supabase Dashboard
2. Перейдите в раздел **Storage**
3. Нажмите **"Create Bucket"**
4. Укажите:
   - **Name**: `bot-assets`
   - **Public**: Да (или настройте RLS политики)
5. Нажмите **"Create bucket"**

## Управление меню

### Создание нового меню

1. На главной странице админ-панели нажмите **"+ Добавить меню"**
2. Заполните основные настройки:
   - **Callback Data** - уникальный идентификатор меню
   - **Тип** - button, menu или command
   - **Порядок** - порядковый номер для сортировки
   - **Активно** - включить/выключить меню
3. Перейдите в раздел **"Текст и фото"** для добавления контента
4. Перейдите в раздел **"Кнопки"** для добавления дочерних кнопок
5. Нажмите **"Сохранить"**

### Редактирование меню

1. В списке меню нажмите **"Редактировать"** на нужном элементе
2. Внесите изменения в нужных разделах
3. Нажмите **"Сохранить"**

### Управление текстом и фотографиями

#### Раздел "Текст и фото"

- **Основной текст** - основной текст сообщения для каждого языка (KZ, RU, EN)
- **Текст перед фото** - текст, который отображается перед фотографией
- **Фотография** - загрузите изображение с локального компьютера (поддерживаются форматы: JPG, PNG, GIF)
  - Максимальный размер: 5MB
  - Фотографии сохраняются в Supabase Storage
  - URL фотографии автоматически сохраняется в базе данных
- **Текст после фото** - текст, который отображается после фотографии

#### Загрузка фотографий

1. Выберите язык (KZ, RU, EN)
2. Нажмите **"Загрузить фото"**
3. Выберите изображение с вашего компьютера
4. Дождитесь завершения загрузки
5. Фотография будет автоматически сохранена и отображена в превью

### Управление кнопками

#### Раздел "Кнопки"

Кнопки - это дочерние элементы меню, которые отображаются как inline-кнопки в Telegram боте.

#### Добавление новой кнопки

1. В разделе **"Кнопки"** нажмите **"+ Добавить кнопку"**
2. Заполните поля:
   - **Текст (KZ)** - текст кнопки на казахском языке
   - **Текст (RU)** - текст кнопки на русском языке
   - **Текст (EN)** - текст кнопки на английском языке
   - **Callback Data** - уникальный идентификатор для обработки нажатия
3. Кнопка автоматически добавится в список

#### Изменение порядка кнопок

- Используйте кнопки **↑** и **↓** для перемещения кнопок вверх/вниз
- Порядок автоматически сохраняется при сохранении меню

#### Удаление кнопки

- Нажмите **"Удалить"** на нужной кнопке
- Кнопка будет удалена при сохранении меню

### Управление порядком меню

На главной странице вы можете изменить порядок отображения меню:

- **↑** - переместить меню вверх
- **↓** - переместить меню вниз

### Активация/деактивация меню

- Нажмите кнопку **⏸** для деактивации меню
- Нажмите кнопку **▶** для активации меню
- Деактивированные меню не отображаются в боте

### Удаление меню

1. Нажмите кнопку **🗑** на нужном меню
2. Подтвердите удаление
3. **Внимание**: Все дочерние кнопки также будут удалены

## Структура данных

### Меню (bot_menus)
- Основные элементы меню
- Могут иметь дочерние кнопки (через parent_id)
- Имеют порядок отображения (order_index)

### Тексты (bot_texts)
- Многоязычный контент для каждого меню
- Поддерживаются языки: KZ, RU, EN
- Могут содержать фотографии (photo_url)

### Кнопки
- Дочерние элементы меню (type = 'button', parent_id != null)
- Имеют тексты на разных языках
- Имеют callback_data для обработки нажатий

## Рекомендации

1. **Используйте понятные Callback Data**: например, `menu_about`, `button_contact`
2. **Загружайте оптимизированные изображения**: используйте сжатие для уменьшения размера файлов
3. **Проверяйте порядок**: убедитесь, что порядок меню и кнопок логичен
4. **Тестируйте изменения**: после сохранения проверьте работу в боте
5. **Резервное копирование**: регулярно делайте резервные копии данных через Supabase Dashboard

## Устранение неполадок

### Фотографии не загружаются

- Убедитесь, что Storage bucket `bot-assets` создан
- Проверьте, что bucket публичный или настроены правильные RLS политики
- Проверьте размер файла (максимум 5MB)
- Проверьте формат файла (должен быть изображением)

### Кнопки не отображаются

- Убедитесь, что кнопки имеют тексты хотя бы на одном языке
- Проверьте, что родительское меню активно
- Проверьте, что callback_data заполнен

### Изменения не сохраняются

- Проверьте права доступа (должна быть роль admin)
- Проверьте консоль браузера на наличие ошибок
- Убедитесь, что все обязательные поля заполнены
