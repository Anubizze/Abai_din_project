# Инструкция по проверке мобильной версии

## Как проверить мобильную версию:

1. **В браузере (Chrome/Edge):**
   - Откройте DevTools (F12)
   - Нажмите на иконку устройства (Toggle device toolbar) или Ctrl+Shift+M
   - Выберите устройство (например, iPhone 12, Galaxy S20) или установите ширину < 768px
   - Обновите страницу (Ctrl+R или F5)

2. **На реальном мобильном устройстве:**
   - Откройте админку на телефоне
   - Должны быть видны карточки вместо таблицы
   - Вверху должен быть синий индикатор "МОБИЛЬНАЯ ВЕРСИЯ АКТИВНА"

3. **Что должно быть видно:**
   - ✅ Карточки вместо таблицы
   - ✅ Синий индикатор вверху (временно для теста)
   - ✅ Кнопка "✏ Редактировать" внизу каждой карточки
   - ✅ Все кнопки доступны для нажатия
   - ✅ Вертикальный скролл работает

## Если не видно изменений:

1. Остановите dev-сервер (Ctrl+C)
2. Удалите папку `.next`:
   ```powershell
   Remove-Item -Recurse -Force .next
   ```
3. Перезапустите:
   ```powershell
   npm run dev
   ```
4. Очистите кеш браузера: Ctrl+Shift+Delete
5. Откройте в режиме инкогнито

## Breakpoint:
- Desktop: ≥ 768px (таблица)
- Mobile: < 768px (карточки)
