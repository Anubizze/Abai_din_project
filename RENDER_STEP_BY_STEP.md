# 🚀 Пошаговая инструкция: Деплой на Render.com

## 📋 Шаг 1: Регистрация и вход

1. Откройте [https://render.com](https://render.com)
2. Нажмите **"Get Started"** или **"Sign Up"**
3. Войдите через **GitHub** (рекомендуется) или создайте аккаунт
4. Подтвердите email если потребуется

---

## 📝 Шаг 2: Создание Background Worker

### Вариант A: Через Blueprint (Автоматически) - РЕКОМЕНДУЕТСЯ

1. В [Render Dashboard](https://dashboard.render.com) нажмите **"New +"** (вверху справа)
2. Выберите **"Blueprint"**
3. Нажмите **"Connect account"** и подключите ваш GitHub аккаунт (если еще не подключен)
4. Выберите репозиторий: **`Adil78124/Abai_din_bot`**
5. Render автоматически обнаружит файл `render.yaml`
6. Нажмите **"Apply"** или **"Create Blueprint"**
7. Render создаст сервис автоматически

### Вариант B: Ручное создание (Если Blueprint не работает)

1. В [Render Dashboard](https://dashboard.render.com) нажмите **"New +"**
2. Выберите **"Background Worker"**
3. Нажмите **"Connect account"** и подключите GitHub (если еще не подключен)
4. Выберите репозиторий: **`Adil78124/Abai_din_bot`**

**Настройки сервиса:**
- **Name**: `abai-din-bot` (или любое другое имя)
- **Region**: Выберите ближайший (например, `Frankfurt` или `Oregon`)
- **Branch**: `main`
- **Root Directory**: (оставьте пустым)
- **Environment**: `Python 3`
- **Build Command**: `pip install -r requirements.txt`
- **Start Command**: `python main.py`
- **Plan**: 
  - **Free** - для тестирования (бесплатно, но "засыпает" после 15 мин неактивности)
  - **Starter** - $7/месяц (рекомендуется для production)

5. Нажмите **"Create Background Worker"**

## 🔐 Шаг 3: Настройка переменных окружения (КРИТИЧЕСКИ ВАЖНО!)

После создания сервиса:

1. В вашем сервисе нажмите на вкладку **"Environment"** (слева в меню)
2. В разделе **"Environment Variables"** нажмите **"Add Environment Variable"**
3. Добавьте каждую переменную по отдельности:

### Переменная 1: TELEGRAM_BOT_TOKEN
- **Key**: `TELEGRAM_BOT_TOKEN`
- **Value**: Ваш токен бота (получите у @BotFather в Telegram)
- Нажмите **"Save Changes"**

### Переменная 2: SUPABASE_URL
- **Key**: `SUPABASE_URL`
- **Value**: `https://lnlcnwiswteoaqdyddqm.supabase.co` (или ваш URL)
- Нажмите **"Save Changes"**

### Переменная 3: SUPABASE_KEY
- **Key**: `SUPABASE_KEY`
- **Value**: Ваш ключ Supabase (из Settings → API в Supabase)
- Нажмите **"Save Changes"**

### Переменная 4: ADMIN_SECRET_CODE (опционально)
- **Key**: `ADMIN_SECRET_CODE`
- **Value**: `Admin04394` (или ваш секретный код)
- Нажмите **"Save Changes"**

### Переменная 5: PYTHONUNBUFFERED
- **Key**: `PYTHONUNBUFFERED`
- **Value**: `1`
- Нажмите **"Save Changes"**

**✅ Итого должно быть 5 переменных окружения**

---

## 🚀 Шаг 4: Запуск деплоя

1. После добавления всех переменных окружения перейдите на вкладку **"Events"** или **"Logs"**
2. Нажмите **"Manual Deploy"** → **"Deploy latest commit"**
3. Дождитесь завершения деплоя (обычно 2-5 минут)
4. Следите за логами в реальном времени

---

## ✅ Шаг 5: Проверка работы

1. Откройте вкладку **"Logs"** в вашем сервисе
2. Вы должны увидеть сообщения:
   ```
   [OK] Токен загружен успешно
   [OK] Бот создан
   [OK] Бот подключен: @your_bot_username
   [OK] Бот запущен и ожидает сообщений...
   ```

3. Откройте Telegram и отправьте `/start` вашему боту
4. Бот должен ответить!

## 🔍 Где найти важные разделы:

### В Render Dashboard для вашего сервиса:

- **Overview** - общая информация о сервисе
- **Logs** - логи работы бота (здесь видно все сообщения)
- **Metrics** - метрики использования (CPU, память)
- **Events** - история деплоев и событий
- **Environment** - переменные окружения (здесь вы их добавляли)
- **Settings** - настройки сервиса

## ⚠️ Важные моменты:

### Free Tier (бесплатный план):
- ✅ Бесплатно
- ⚠️ Сервис "засыпает" после 15 минут неактивности
- ⚠️ Первый запрос после пробуждения занимает 30-60 секунд
- ⚠️ Для production лучше использовать платный план

### Автоматический деплой:
- При каждом push в ветку `main` на GitHub, Render автоматически запустит новый деплой
- Это можно отключить в Settings → Auto-Deploy

### Обновление бота:
1. Внесите изменения в код
2. Закоммитьте и запушьте в GitHub:
   ```cmd
   git add .
   git commit -m "Update: описание изменений"
   git push origin main
   ```
3. Render автоматически начнет новый деплой (или запустите Manual Deploy)

## 🐛 Решение проблем:

### Бот не отвечает:
1. Откройте **Logs** в Render Dashboard
2. Проверьте, есть ли ошибки (красным цветом)
3. Убедитесь, что все переменные окружения добавлены
4. Проверьте токен бота

### Ошибка "TELEGRAM_BOT_TOKEN не установлен":
- Перейдите в **Environment** → проверьте, что переменная `TELEGRAM_BOT_TOKEN` добавлена
- Убедитесь, что значение правильное (без пробелов в начале/конце)

### Ошибка подключения к Supabase:
- Проверьте `SUPABASE_URL` и `SUPABASE_KEY` в **Environment**
- Убедитесь, что Supabase проект активен

### Сервис не запускается:
1. Откройте **Logs**
2. Найдите ошибку (обычно в начале логов)
3. Частые проблемы:
   - Отсутствует зависимость → добавьте в `requirements.txt`
   - Неправильная версия Python → проверьте в Settings
